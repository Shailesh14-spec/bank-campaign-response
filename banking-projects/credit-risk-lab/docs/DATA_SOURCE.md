# Dataset provenance

Yeh, I. (2009). Default of Credit Card Clients [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C55S3H.

30,000 anonymised client records; financial history precedes a next-month default label.

- Original source: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
- Acquisition endpoint used: https://archive.ics.uci.edu/static/public/350/default+of+credit+card+clients.zip
- Acquired: 25 October 2026.
- SHA-256 of extracted/received source file: `30c6be3abd8dcfd3e6096c828bad8c2f011238620f5369220bd60cfc82700933`.

UCI states CC BY 4.0: https://creativecommons.org/licenses/by/4.0/. The project downloads the original workbook, records its checksum, and does not redistribute raw rows.

The original file is read without modifying its bytes. Feature engineering, split assignment, deduplication policies, probability calibration and aggregate outputs are adaptations documented in the protocol. No private employer or user banking data is used. Checksum or shape changes cause the analysis to stop for review rather than silently accepting a different dataset.
